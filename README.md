# BehifyVPN — Xray JSON profiles

هفت کانفیگ مستقل Xray برای آزمایش و استفاده در کلاینت‌هایی که **اشتراک آرایه‌ای از کانفیگ‌های کامل Xray JSON** را پشتیبانی می‌کنند.

> **وضعیت: آماده برای بازبینی و انتشار آزمایشی؛ اتصال واقعی و آپدیت داخل اپ هنوز تست نشده است.** این مخزن سرور VPN ارائه نمی‌کند؛ بیشتر outboundها از نوع `freedom` (اتصال مستقیم، گاهی با Fragment) هستند، نه پراکسی‌ای که IP شما را پنهان کند.

## لینک اشتراک v2rayNG

پس از ایجاد مخزن **عمومی** با نام `behify-configs` زیر حساب `behifyn` و push کردن محتوا، این URL قابل استفاده خواهد بود:

```text
https://raw.githubusercontent.com/behifyn/behify-configs/main/sub/v2rayng.json
```

این لینک تا زمان ایجاد مخزن و push **فعال نیست**. در v2rayNG بخش `Subscriptions` / `Subscription group settings`، آدرس را اضافه کنید، سپس `Update subscription` بزنید. در صورت پشتیبانی نسخه برنامه، هر هفت پروفایل از آرایه JSON وارد می‌شوند. **پیش از توصیه عمومی، روی دستگاه واقعی و دو چرخه آپدیت تست شود**؛ بعضی نسخه‌ها مشکلات تکرار پروفایل و تبدیل اعداد داشته‌اند.

## Hiddify

این هفت فایل **native Xray JSON** هستند؛ Hiddify مستقیماً با این قالب کامل، شامل Fragment و routing اختصاصی Xray، کار نمی‌کند. بنابراین **هیچ لینک ساختگی Hiddify** در این مخزن وجود ندارد. برای Hiddify باید بعداً بر اساس پشتیبانی واقعی sing-box/Hiddify پروفایل مستقل ساخته و با اتصال واقعی تست شود؛ تبدیل مستقیم معادل عملکردی نیست.

## فایل‌ها

- `profiles/behify-01.json` تا `profiles/behify-07.json`: پروفایل‌های مستقل بازبینی‌شده
- `sub/v2rayng.json`: اشتراک تولیدشده برای v2rayNG، از نوع آرایه کامل Xray JSON
- `scripts/build.py`: ساخت قطعی و کنترل ارجاع‌های داخلی، localhost و یکتایی نام‌ها
- `docs/adjustments.json`: تغییرات کوچک اعمال‌شده نسبت به فایل اولیه
- `docs/compatibility.md`: محدودیت‌ها و آزمایش پذیرش

## ویرایش و انتشار تغییرات

پروفایل موردنظر را در `profiles/` ویرایش و سپس اجرا کنید:

```bash
python scripts/build.py
python scripts/build.py --check
```

هر دو فایل پروفایل و اشتراک تولیدشده باید در commit قرار بگیرند. آدرس اشتراک با آپدیت فایل `main/sub/v2rayng.json` **ثابت می‌ماند**؛ دریافت نسخه جدید بستگی به امکان دسترسی به GitHub Raw و قابلیت آپدیت کلاینت دارد. GitHub Actions صرفاً اعتبارسنجی ایستا می‌کند و کانفیگ را در شبکه ایران یا روی کلاینت اجرا نمی‌کند.

## هشدارهای امنیتی و سازگاری

- برخی پروفایل‌ها از SOCKS خارجی با یک IP ثابت برای تلگرام استفاده می‌کنند. پیش از عمومی‌کردن، مالکیت، پایداری و اعتماد به آن را بررسی کنید. مسیرهای مستقیم، IP کاربر را از مقصد پنهان نمی‌کنند.
- تنظیمات Fragment/Finalmask به نسخه و پشتیبانی Xray-core وابسته است؛ سازگاری در همه نسخه‌های کلاینت تضمین نیست.
- در پنج پروفایل inbound مربوط به DNS صریحاً به localhost محدود شد تا به صورت غیرعمدی در شبکه باز نماند.
- در چهار پروفایل مرجع DNS ناموجود به تگ فعلی `dns-frag-out` تغییر یافت. این **یک فرض اصلاحی محدود** است که نیازمند آزمون runtime است.
- در پروفایل ۵ لاگ debug/DNS برای انتشار عمومی خاموش شد.
- بعضی DNSهای خارجی یا آدرس‌های hardcoded ممکن است در برخی شبکه‌ها غیرقابل دسترس باشند. نتیجه اتصال قابل پیش‌بینی قطعی نیست.

این مخزن عمداً فهرست جعلی `vless://` یا فایل sing-box با رفتار متفاوت تولید نمی‌کند.
